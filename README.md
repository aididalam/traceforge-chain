# TraceForge Chain

Part of [TraceForge](https://github.com/aididalam/traceforge). See the parent repository for setup and deployment.

Runs the private Hyperledger Besu blockchain and QBFT validator network.
Provides genesis configuration, persistent node storage and Docker networking.
Remote nodes synchronize with this network; validators participate after election.
